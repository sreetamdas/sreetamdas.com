# URL state, in code

- `validateSearch` parses once
- `loaderDeps` makes data dependencies explicit
- `Route.useSearch()` returns the validated shape

```tsx
createFileRoute("/stats")({
  validateSearch: parseStatsSearch,
  loaderDeps: ({ search }) => search,
});
```

# Loader data is cached

- route owns the data contract
- `loaderDeps` shapes the cache key
- `staleTime` says how fresh it is

```tsx
createFileRoute("/stats")({
  loaderDeps: ({ search }) => search,
  loader: ({ deps }) => getStats({ data: deps }),
  staleTime: 1000 * 60 * 5,
});
```

---

# Server functions / server routes

- functions: app-to-server RPC
- routes: public HTTP endpoints
- validated input, typed output
- `GET` when the call should be cacheable

```tsx
const getStats = createServerFn({ method: "GET" })
  .validator(parseStatsInput)
  .handler(async ({ data }) => loadStats(data));
```

---

# Middleware across the boundary

- `.client()` before the call leaves the browser
- `.server()` before the handler runs
- one boundary across the network

```tsx
const boundaryMiddleware = createMiddleware({ type: "function" })
  .client(async ({ next }) => next({ context: { source: "browser" } }))
  .server(async ({ next }) => next({ context: { requestId: crypto.randomUUID() } }));
```

# Rendering is a dial

- full SSR
- data-only SSR

# Streaming SSR

- shell now
- slow data later
- return an un-awaited promise

```tsx
loader: async ({ deps }) => ({
  shell: await getFastData(deps),
  slowPanel: getSlowData(deps),
});
```

---

# Build-time server functions

- same primitive
- different clock
- build once, serve static data

```tsx
export const getHighlightedCode = createServerFn({ method: "GET" })
  .middleware([staticFunctionMiddleware])
  .handler(async () => loadRwcCodeSamples());
```
